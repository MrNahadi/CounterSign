# 0013. Product AI runs on the Gemini Developer API through `@google/genai` 2.27.0, with `gemini-3.8-flash` for every role

Status: accepted. The model choice (`gemini-3.8-flash` for every role) is superseded by ADR 0017; the rest stands.
Decided-by: answerer (researched). The move from Anthropic to Google Gemini is the owner's decision, stated in session on 16 Oct 2026; this ADR records the technical "how".
Question: Gemini migration, G1, G3, G4 and G7 (16 Oct 2026). Which SDK version and API route, which model and thinking setting per role, what replaces `strict: true` tools and structured outputs, and how do we keep prompt caching, for the Resolve agent (both modes), the mandate compiler and the Risk desk analyst?
Decision:
- **SDK.** Pin `@google/genai` 2.27.0 (published 2 Oct 2026) in `apps/resolve-agent` and `apps/console` (mandate compiler and Risk desk server routes). It depends on `ws`, `p-retry`, `protobufjs` and `google-auth-library`, has an *optional* peer `@modelcontextprotocol/sdk` ^1.25.2 (1.32.1 satisfies it), `engines.node >=20`, `"type": "module"`, and no dependency on zod or `zod-to-json-schema`.
- **API route.** Gemini Developer API (`generativelanguage.googleapis.com`, SDK default `v1beta`) with an API key from Google AI Studio. Not Vertex AI / Gemini Enterprise Agent Platform. Construct the client as `new GoogleGenAI({ apiKey: env.GEMINI_API_KEY, vertexai: false })`, with the key validated by the zod env schema. Passing both explicitly stops a stray `GOOGLE_API_KEY` (which the SDK prefers over `GEMINI_API_KEY`) or `GOOGLE_GENAI_USE_VERTEXAI` / `GOOGLE_GENAI_USE_ENTERPRISE` from changing the route.
- **Endpoint.** Call `ai.models.generateContent` (stateless; we own the history). Don't use the Interactions API (`v1beta2`, stores state server-side by default), `ai.chats` (curates history), or automatic function calling.
- **Models.** `gemini-3.8-flash` (stable, no shutdown date announced) for the Resolve agent, the mandate compiler and the Risk desk analyst. The fallback is `gemini-3.6-flash` under the rules in ADR 0015. Never use `gemini-flash-latest` (hot-swapped) or a preview ID. Records include `response.modelVersion` from every call.
- **Thinking.** Always set `config.thinkingConfig.thinkingLevel` explicitly: `ThinkingLevel.MEDIUM` for the Resolve agent, `ThinkingLevel.HIGH` for the compiler, `ThinkingLevel.LOW` for the Risk desk analyst (Studio's effort picker may offer `MEDIUM`). Never send `thinkingBudget`: it is legacy, and combining it with `thinkingLevel` returns 400. Never send `MINIMAL` to 3.8 Flash, which rejects it. Don't set `temperature`, `topP` or `topK`, because 3.8 Flash ignores them and Google advises leaving Gemini 3 at its defaults.
- **Strict tools.** `config.toolConfig.functionCallingConfig.mode = FunctionCallingConfigMode.VALIDATED`. It constrains the model to a schema-valid function call or plain text, and from Gemini 3 onwards it also enforces required parameters. Declare tools with `parametersJsonSchema`, never `parameters` (the OpenAPI subset). The two are mutually exclusive.
- **Structured output.** `config.responseMimeType = "application/json"` plus `config.responseJsonSchema`, generated from the zod 4 schema with `z.toJSONSchema` and with `$schema` removed. Parse the result with the same zod schema (`safeParse`). A parse failure means no draft is produced. The compiler request sends no tools. Model-facing schemas use only the documented subset: `type` (a `["x","null"]` array for nullable), `properties`, `required`, `additionalProperties`, `enum`, `format` (date-time, date, time), `minimum`, `maximum`, `items`, `prefixItems`, `minItems`, `maxItems`, `title`, `description` and `anyOf`. Use no `oneOf`, `allOf`, `not`, `const`, `pattern`, `propertyNames` or typed records. Anything the subset can't say is enforced by zod refinements after parsing.
- **Caching.** Rely on implicit caching. Don't create explicit caches.
- **Types.** `import type` for SDK types. Import SDK enums (`FunctionCallingConfigMode`, `ThinkingLevel`, `HarmCategory`, `HarmBlockThreshold`) as values, which `erasableSyntaxOnly` allows because we don't declare enums ourselves. Compare `finishReason` as a string, because the API can return values the 2.27.0 enum lacks (`MISSING_THOUGHT_SIGNATURE`, `MALFORMED_RESPONSE`).
Basis:
- npm registry: `@google/genai` dist-tag `latest` is 2.30.0 (15 Oct 2026). 2.27.0 was published 2026-10-02T18:24Z, and its manifest lists the dependencies, optional peer, engines and type above: https://registry.npmjs.org/@google/genai/2.27.0. The 2.26–2.30 changelog only adds continuation tokens (Gemini 4 long outputs) and Interactions items: https://github.com/googleapis/js-genai/blob/main/CHANGELOG.md
- SDK env handling (`GOOGLE_API_KEY` before `GEMINI_API_KEY`; Vertex or Enterprise flags from env): https://github.com/googleapis/js-genai/blob/v2.27.0/src/node/node_client.ts. README: Node 20+ now and Node 22+ from 3.0.0; AFC on direct `generateContent` calls goes away in the next major; built-in MCP support is experimental: https://github.com/googleapis/js-genai
- "While `generateContent` remains fully supported, we recommend the Interactions API for all new development": https://ai.google.dev/gemini-api/docs/migrate-to-interactions
- Models: 3.8 Flash is stable and supports function calling, structured outputs, thinking (low, medium, high) and caching: https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash. No shutdown date for 3.8, 3.6 or 3.5 Flash-Lite. 3.1 Flash-Lite shuts down 7 May 2027. 2.5 models are limited to recent users. Retired 3.7 Flash routes to 3.8 Flash: https://ai.google.dev/gemini-api/docs/deprecations (updated 2026-10-12)
- Thinking levels and defaults per model: https://ai.google.dev/gemini-api/docs/thinking. "`thinking_level="MINIMAL"` is not available for 3.8 Flash"; sampling parameters "are ignored by the backend": https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/guides/gemini-3-8-flash. Using `thinking_level` with legacy `thinking_budget` returns 400; keep temperature at 1.0: https://ai.google.dev/gemini-api/docs/gemini-3
- VALIDATED "ensures function schema adherence": https://ai.google.dev/gemini-api/docs/generate-content/function-calling. "Starting with Gemini 3, this mode also enforces the presence of required parameters": https://docs.cloud.google.com/vertex-ai/generative-ai/docs/multimodal/function-calling. `parametersJsonSchema` is mutually exclusive with `parameters`: https://ai.google.dev/api/generate-content
- Structured output keyword subset; "The model ignores unsupported properties"; "Always validate the final output": https://ai.google.dev/gemini-api/docs/generate-content/structured-output. `responseJsonSchema` needs `responseMimeType`: js-genai `GenerateContentConfig` reference.
- Implicit caching is on by default for 2.5 and newer, with a 4,096-token minimum on 3.8 and 3.6 Flash: https://ai.google.dev/gemini-api/docs/generate-content/caching
Consequences:
- Spike S8 now passes when a `gemini-3.8-flash` call through this client uses a VALIDATED function declaration and, in a separate call, a `responseJsonSchema` output, and the ADR 0015 response check is in place. S8 also runs `tsc --noEmit` against the SDK under our tsconfig on Node 26.
- `.env.example` replaces `ANTHROPIC_API_KEY` with `GEMINI_API_KEY`. Don't set `GOOGLE_API_KEY` anywhere.
- The `packages/mandate`, `packages/verifiers` and `packages/ledger` no-AI-SDK test bans `@google/genai` (and keeps banning `@anthropic-ai/sdk`). The compiler call lives in the console server, not in `packages/mandate`.
- The Mandate schema is designed to fit the subset: explicit properties instead of maps with dotted keys, always-array `action`, single-value `enum` instead of `const`, integer minor units for money.
- Cache hits need a byte-stable `systemInstruction` (no dates or ticket data), tool declarations in a fixed order (sorted by name), unchanged config between steps, and append-only history. Check `usageMetadata.cachedContentTokenCount` > 0 from the second loop step. Explicit caches are out: tools, system instruction and tool config would have to live inside the cache (a request that sets them returns 400), storage is billed by the hour, and 3.5 Flash-Lite has no explicit caching on the free tier.
- The model choice depends on the owner's free-vs-paid decision (escalated 16 Oct 2026). If the owner chooses free tier only, a new ADR moves every role to `gemini-3.5-flash-lite`, because Flash's free-tier daily quota is reported at about 20 requests.
- Pricing for 3.8 and 3.6 Flash doubles on 1 Jan 2027, after the 22 Dec end of the demo.
