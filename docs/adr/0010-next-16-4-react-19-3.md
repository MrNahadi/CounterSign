# 0010. Next.js 16.4.2 and React 19.3.1, not the boilerplate's 16.3.6 and 19.2.8

Status: accepted
Decided-by: answerer (researched)
Question: Phase 1 constitution, Q10. For AG Studio 3.0.0 compatibility, should we use Next 16.4.2 + React 19.3.1, or the boilerplate's 16.3.6 + 19.2.8?
Decision:
- Pin `next` 16.4.2 and `react` / `react-dom` 19.3.1 in both Next apps (console and storefront).
- Keep the boilerplate's AG pins: `ag-studio` 3.0.0, `ag-studio-react` 3.0.0, and `ag-grid-community` / `ag-grid-react` 36.2.0.
- When copying the boilerplate, don't carry over its Next.js or React versions.
- Run spike S9 on these versions.
Basis:
- GHSA-2464-fhr4-w9xw, a Next.js advisory published 14 Oct 2026: critical (CVSS 9.5) remote code execution in image processing of SVG files on glibc Linux, which is what Render runs. It affects "> 16.0.0 <= 16.4.0", so 16.3.6 is affected. Patched in 16.4.1: https://github.com/vercel/next.js/security/advisories/GHSA-2464-fhr4-w9xw
- GHSA-xqc2-xf4c-x3h3, a React Server Components advisory published 14 Oct 2026: critical unauthenticated remote code execution. It affects 19.2.0 through 19.2.8 and 19.3.0, and is patched in 19.2.9 and 19.3.1: https://github.com/facebook/react/security/advisories/GHSA-xqc2-xf4c-x3h3
- `ag-studio-react` 3.0.0 declares `react` and `react-dom` peers of "^17.0.0 || ^18.0.0 || ^19.0.0" (npm registry), so 19.3.1 satisfies them.
- Brief §8: the hosted demo is public until 22 Dec 2026. Brief §10, trade-off 3: the judge path works every time.
Consequences:
- Through 22 Dec, watch for Next.js security releases and take patch releases.
- If S9 shows an AG Studio regression on 16.4.2, the fix is a newer AG Studio or a workaround, never a downgrade to an affected Next.js version.
