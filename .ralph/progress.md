# Progress: phase 5, Kikapu storefront and seed (specs/features/05-storefront-and-seed)

- `@countersign/rail-paypal` now has `createPayPalClient({ env, fetch?, sleep?, now? })` (sandbox guard, shared OAuth token cache, 401 re-auth once, safe retries) with `getOrder`, plus `parsePayPalEnv` (returns `missing` and `problems` for CLIs to name), `PayPalConfigError` and `PayPalError` (`kind`: http | network | invalid_response | invalid_request; `call` is kebab-case like `get-order`, `oauth-token`).

## T-002 (done)

Wire amounts come from `toPayPalAmount` in `src/records.ts` (formatMoney with `$` and commas stripped, checked by a parseMoney round trip). The tracker body uses PayPal's `carrier_name_other` field; T-010's live check should confirm it. Test helpers `testClient`, `caught`, `expectNoSecrets` (now also checks `FAKE_VAULT_TOKEN`) and `exposed` live in `test/fake-paypal.ts`.
