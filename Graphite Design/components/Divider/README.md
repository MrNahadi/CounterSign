# Divider

A 1px line that separates groups, horizontal between sections and vertical between toolbar items.

## What you provide

- `<hr class="gr-divider">` between sections, `gr-divider-subtle` inside cards and menus.
- `<span class="gr-divider-v" role="separator" aria-orientation="vertical">` between inline items, 16px tall.

## Rules

- Default is `color-border-default`; subtle is `color-border-subtle`.
- Prefer spacing over lines. Add a divider only when space alone doesn't separate the groups.
